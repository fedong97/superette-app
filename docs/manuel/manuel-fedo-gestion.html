    Chapitre 1

    Installation et première ouverture

    Pour qui : Propriétaire

    FEDONIX 360 s'installe sur un PC Windows (64 bits). Il garde ses données sur le PC lui-même : la caisse fonctionne même sans Internet.

    Ce qu'il faut

    • Un PC Windows 64 bits avec le fichier d'installation Fedonix360-Setup-0.39.0.exe remis par FEDONG.
    • Conseillé : une douchette (lecteur de codes-barres), une imprimante de tickets 80 mm ou 58 mm (USB ou réseau) et un tiroir-caisse branché sur l'imprimante.
    • Une clé USB pour les sauvegardes (chapitre 9).
    Le plus souvent, c'est FEDONG qui installe

    Votre vendeur installe le logiciel, crée le magasin et règle l'imprimante avec vous. Gardez ce manuel près de la caisse.

    Installer le logiciel

    1. Double-cliquez sur le fichier Fedonix360-Setup-…exe. Windows peut demander l'autorisation de l'administrateur du PC : acceptez.
    2. Lisez le contrat de licence et acceptez-le. Le même contrat reste lisible plus tard dans Administration › Licence.
    3. Gardez le dossier d'installation proposé, puis cliquez sur Installer.
    4. À la fin, l'icône FEDONIX 360 apparaît sur le bureau. Double-cliquez dessus pour ouvrir le logiciel.
    Avertissement de Windows

    Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même, seulement si le fichier vient bien de FEDONG.

    Créer le magasin (première ouverture)

    À la toute première ouverture, FEDONIX 360 demande de créer votre magasin et le compte de l'administrateur (le propriétaire).

    1. Tapez le code magasin (2 à 6 caractères, par exemple DLA1) et le nom du magasin. L'adresse, le téléphone et le NIU sont imprimés sur les tickets et factures.
    2. Laissez la case Magasin assujetti à la TVA décochée si vous êtes au régime simplifié : les tickets porteront « TVA non applicable ». Cochez-la si vous êtes au réel (TVA 19,25 %). Elle peut être changée plus tard.
    3. Dans Administrateur, tapez votre nom, un identifiant (par exemple votre prénom) et un code secret de 4 à 8 chiffres, deux fois.
    4. Cliquez sur Créer le magasin.
    Notez le code de l'administrateur

    Écrivez l'identifiant et le code secret de l'administrateur et rangez-les en lieu sûr. C'est le seul compte qui peut tout faire : créer les utilisateurs, activer la licence, restaurer une sauvegarde.

    Le bouton Rejoindre un magasin existant sert seulement pour un deuxième PC du même magasin (chapitre 11).

    Se connecter

    À chaque ouverture, chacun se connecte avec son identifiant et son code secret. Ainsi, chaque vente et chaque opération porte le nom de la personne qui l'a faite.

    Le caissier arrive directement sur la fiche de vente. Le gérant et l'administrateur arrivent sur la page d'accueil, avec de grosses tuiles pour les tâches de tous les jours.

    L'écran est toujours rangé de la même façon :

    • En haut : les menus (Facturation, Vente, Achats, Trésorerie, Produit…). Chacun ne voit que les menus permis par ses droits.
    • Dessous : les onglets rapides (V. cash 1, V. crédit, Stock, Trésorerie…). Un clic ouvre la fenêtre.
    • En bas : la barre d'état. Elle montre le magasin, la caisse, l'utilisateur, le serveur, l'état de la sauvegarde et de la licence. Le lien Changer d'utilisateur est en bas à droite.

    À la première connexion, le Guide de démarrage affiche les cinq premières choses à faire selon votre rôle. Vous le retrouvez dans Aide › Guide de démarrage.

    L'essai de 15 jours

    Sans licence, FEDONIX 360 fonctionne 15 jours en essai, avec toutes ses fonctions. La barre d'état affiche Version d'essai (N j), le nombre de jours qui restent. Avant la fin, activez votre licence (chapitre 10).

    Chapitre 2

    Utilisateurs et droits

    Pour qui : Propriétaire Gérant

    Chaque personne a son propre compte. Son rôle décide de ce qu'elle voit et de ce qu'elle peut faire.

    RôleCe qu'il fait
    AdministrateurTous les droits. Crée les caisses et les utilisateurs, règle les paramètres, active la licence, restaure les sauvegardes. À réserver au propriétaire.
    GérantSuit la journée, contrôle les clôtures et justifie les écarts, reçoit la marchandise, gère le stock, les clients et les commandes. Son code autorise les remises, retours et annulations des caissiers.
    CaissierOuvre sa caisse, vend, encaisse, fait les ventes à crédit et clôture sa caisse.
    Autres rôlesVendeur (comme le caissier), Magasinier (réceptions, transferts, inventaires, pertes), Responsable d'achat (commandes, fournisseurs), Comptable (journaux, TVA, états financiers).

    Créer les caisses

    Dans Administration › Caisses, l'administrateur crée une caisse Espèces par poste de vente. Il peut aussi créer une caisse Électronique (MTN Mobile Money, Orange Money, carte) et une caisse Banque (virement, chèque) pour chaque caissier. Chaque paiement va ensuite dans la caisse de son type.

    Créer un utilisateur

    1. Ouvrez Administration › Utilisateurs.
    2. Cliquez sur Ajouter un utilisateur.
    3. Tapez le nom complet, l'identifiant (ce qu'il tapera pour se connecter) et un code secret en chiffres.
    4. Choisissez le rôle et le magasin.
    5. Pour un caissier, choisissez sa caisse espèces. Sans caisse, il ne peut pas vendre. Choisissez aussi sa caisse électronique et sa caisse banque si vous en avez.
    6. Cliquez sur Enregistrer.
    Code oublié, compte bloqué

    Cliquez sur l'utilisateur dans la liste, tapez un nouveau code puis enregistrez. Après trop de codes faux, le compte est bloqué 15 minutes : l'administrateur peut cliquer sur Débloquer dans la liste.

    Régler les droits

    Les droits par défaut conviennent à la plupart des magasins. Pour les changer :

    1. Ouvrez Administration › Droits par rôle.
    2. Choisissez un groupe à gauche (Facturation, Trésorerie, Gestion des stocks…), ou tapez un mot dans la recherche.
    3. Cochez ou décochez la case du droit dans la colonne du rôle. L'administrateur garde toujours tous les droits.
    4. Le changement vaut pour tous les utilisateurs du rôle, à leur prochaine connexion.

    Pour donner ou retirer un droit à une seule personne sans changer son rôle, utilisez Administration › Privilèges par utilisateur.

    Ce que le caissier ne voit pas

    Par défaut, le caissier ne voit pas les montants de la caisse : il compte à l'aveugle à la clôture et ne voit pas l'attendu. Seul le gérant (ou le comptable) voit les montants et les écarts. Les menus et boutons non permis ne s'affichent pas du tout.

    Chapitre 3

    Articles et prix

    Pour qui : Gérant Propriétaire

    Chaque produit vendu a une fiche article : son nom, son rayon, ses prix et ses codes-barres. Vous pouvez créer les fiches une par une ou importer tout le catalogue depuis Excel.

    La liste des produits

    Ouvrez Produit › Liste des produits (ou l'onglet Produits). Tapez dans la zone jaune pour chercher par nom, code, code-barres ou marque. Cliquez sur un produit pour ouvrir sa fiche.

    Créer une fiche article

    1. Cliquez sur Nouvel article.
    2. Tapez la désignation (le nom imprimé sur le ticket). Laissez le code article vide : il est numéroté tout seul.
    3. Choisissez le rayon / famille et l'unité de vente : pièce, kg ou litre. Pour créer un rayon, utilisez Nouveau rayon plus bas.
    4. Dans Conditionnements et prix, la ligne 1 est le conditionnement d'achat (CARTON, CASIER, PALETTE…) avec son prix d'achat, son prix de revient (achat plus transport) et son prix de vente.
    5. Si vous vendez aussi au détail, cochez la ligne 2 : tapez le nom (BOÎTE, CANETTE, PIÈCE…), le diviseur (24 boîtes dans le carton) et le prix de vente. L'achat et le revient se calculent seuls. Les colonnes Gros et Sup. gros sont les prix des clients grossistes.
    6. Plus bas, scannez le code-barres du produit avec la douchette, ou cliquez sur Générer un code interne pour un produit sans code-barres.
    7. Réglez si besoin le stock d'alerte, cochez Périssable (la date limite sera demandée à la réception) ou Touche rapide en caisse. Vous pouvez ajouter une photo.
    8. Cliquez sur Enregistrer.
    Changer un prix

    Ouvrez la fiche, changez le prix de vente et enregistrez. L'historique des prix reste sur la fiche. Pensez à imprimer la nouvelle étiquette : Produit › Étiquettes de rayon liste les étiquettes à refaire.

    Importer le catalogue depuis Excel

    Si vous avez déjà la liste de vos produits dans Excel, vous pouvez l'importer en une fois.

    1. Dans Excel, mettez les colonnes dans cet ordre, avec ces en-têtes sur la première ligne : 
      designation;code_barres;prix_vente;prix_achat;tva;unite;rayon;famille
Riz parfumé 5 kg;6111234567890;4500;3800;0;piece;Épicerie;Riz
      Pour l'unité, écrivez piece, kg ou litre.
    2. Dans Excel : Fichier › Enregistrer sous, type CSV. Choisissez de préférence CSV UTF-8 pour garder les accents.
    3. Dans FEDONIX 360, ouvrez Produit › Liste des produits et cliquez sur Importer (CSV).
    4. Choisissez le fichier. Le nombre de lignes lues s'affiche : cliquez sur Importer.
    5. Vérifiez quelques fiches dans la liste des produits.

    Produits vendus au poids

    Pour la viande, le poisson ou les légumes au kilo, choisissez l'unité Kg et le prix au kilo. Si votre balance imprime des étiquettes à code-barres, tapez le code balance (PLU) du produit sur sa fiche (5 chiffres). À la caisse, l'étiquette scannée donne directement le poids ou le prix.

    Chapitre 4

    La caisse : ouvrir, vendre, clôturer

    Pour qui : Caissier Gérant

    La journée d'un caissier se fait en trois temps : ouvrir sa caisse le matin, vendre, puis clôturer le soir en comptant les billets.

    Ouvrir la caisse le matin

    Aucune vente n'est possible tant que la caisse n'est pas ouverte. La fiche de vente affiche alors La caisse est fermée.

    1. Cliquez sur Ouvrir la caisse dans Trésorerie (ou ouvrez l'onglet Trésorerie).
    2. Cliquez sur Ouvrir la caisse….
    3. Le fond laissé dans le tiroir à la dernière clôture est proposé. Vérifiez-le. Pour compter billet par billet, cliquez sur Compter par coupures.
    4. Cliquez sur Ouvrir la caisse. Votre caisse électronique (MoMo, Orange Money) s'ouvre en même temps.
    Fond plus élevé que la veille

    Si vous mettez plus d'argent que le fond de la veille, le complément vient de la caisse centrale : le code du gérant est demandé et un bon est imprimé.

    Vendre

    Ouvrez l'onglet V. cash 1 (vente au comptant). Le curseur est dans la zone jaune.

    1. Avec la douchette : scannez le code-barres. Le produit s'ajoute avec la quantité 1.
    2. Plusieurs pièces : tapez la quantité, une étoile, puis scannez. Exemple : 6* puis le code du Coca donne 6 Coca. Les touches + et − changent la quantité de la ligne choisie.
    3. Sans code-barres : tapez les premières lettres du nom (2 lettres suffisent). Une liste s'ouvre avec le prix et le stock. Choisissez avec les flèches puis Entrée.
    4. Une petite fenêtre demande la quantité. Tapez-la puis Entrée.
    5. Pour enlever une ligne, cliquez dessus puis Suppr ou le bouton Enlever.

    Un produit épuisé reste dans la liste, marqué Épuisé, mais ne peut pas être vendu.

    Vendre au poids

    Pour un produit au kilo, la fenêtre demande la quantité en kg. Tapez le poids lu sur la balance avec une virgule, par exemple 1,250 pour 1,250 kg, puis Entrée. Le prix se calcule tout seul. Si la balance imprime une étiquette à code-barres, scannez simplement l'étiquette.

    Encaisser en espèces

    1. Cliquez sur les billets reçus du client (1 000, 2 000, 5 000, 10 000) ou tapez le montant. E montre l'encaissé et R la monnaie à rendre.
    2. Appuyez sur F4 (ou Valider / Nouv.). Le ticket s'imprime et une nouvelle fiche commence.

    Pour réimprimer le dernier ticket : F2. Pour une facture A4 du dernier ticket : F9.

    Encaisser par MTN Mobile Money, Orange Money ou carte

    1. Appuyez sur Ctrl+E (ou Encaisser).
    2. Cliquez sur le moyen de paiement : MTN Mobile Money, Orange Money, Carte bancaire ou Bon d'achat.
    3. Tapez le montant, puis la référence de la transaction reçue par SMS. Elle est obligatoire.
    4. Cliquez sur Ajouter le paiement.
    5. Le client paie une partie en espèces et le reste en MoMo ? Ajoutez simplement deux paiements.
    6. Quand Reste à payer est à 0, cliquez sur Valider le ticket.
    Vérifiez le SMS avant de valider

    Ne validez un paiement MoMo ou Orange Money qu'après avoir vu le SMS de confirmation. La référence sert à retrouver le paiement à la clôture.

    Mettre un ticket en attente

    Un client a oublié quelque chose ? Mettez son ticket de côté pour servir le suivant.

    1. Appuyez sur F3 (Mise en attente). La fiche se vide.
    2. Servez les autres clients normalement. Le bouton Ouvrir (en attente) affiche le nombre de tickets en attente.
    3. Quand le client revient, appuyez sur F10, choisissez son ticket et Entrée.

    Faire une remise

    1. Cliquez sur la ligne du produit, puis appuyez sur F6.
    2. Choisissez En % ou En FCFA, tapez la remise et cliquez sur Appliquer.
    3. Si vous n'avez pas le droit de faire des remises, le code du gérant est demandé à l'encaissement.

    Les promotions enregistrées par le gérant (Vente › Promotions) s'appliquent toutes seules, sans code.

    Retour d'un client, annulation d'un ticket

    1. Dans la fiche de vente, ouvrez la liste Action et choisissez Retour client.
    2. Tapez le numéro du ticket (imprimé sur le ticket du client) et cliquez sur Rechercher.
    3. Pour chaque article rapporté, tapez la quantité retournée.
    4. Choisissez le mode de remboursement et tapez le motif.
    5. Cliquez sur Valider le retour : le gérant tape son code. Les articles reviennent en stock.

    Pour annuler un ticket entier de la journée : Action › Annuler un ticket, avec un motif et le code du gérant. La liste Action sert aussi aux apports et prélèvements d'espèces, aux règlements des clients à crédit et aux dépenses payées avec l'argent du tiroir.

    Clôturer la caisse le soir

    La clôture se fait à l'aveugle : vous comptez d'abord les billets, sans voir ce que le logiciel attend.

    1. Terminez ou mettez en attente le ticket en cours, puis ouvrez l'onglet Trésorerie.
    2. Cliquez sur Fermer la caisse….
    3. Comptez les espèces du tiroir et tapez le nombre de billets et de pièces de chaque valeur. Le total se calcule en bas.
    4. Cliquez sur Valider le comptage.
    5. Indiquez le fond laissé dans le tiroir pour demain. Le reste est versé à la caisse centrale.
    6. Cliquez sur Clôturer et verser. Le bon de versement s'imprime : remettez-le au gérant avec l'argent, et faites-le signer.

    Ensuite, dans Mes autres caisses, cliquez sur Clôturer… en face de votre caisse électronique. Tapez pour chaque moyen (MTN, Orange, carte) le montant relevé sur le téléphone ou le terminal, puis validez.

    Caisse oubliée ouverte

    Une caisse restée ouverte d'un jour sur l'autre est signalée. Fermez la journée d'hier avant d'ouvrir celle d'aujourd'hui.

    Écart de caisse et rapport Z (gérant)

    Après la clôture, le logiciel compare le comptage avec l'attendu. Si l'écart dépasse le seuil (500 FCFA par défaut, réglable dans Administration › Paramètres), la journée reste « écart à justifier » et la barre d'état du gérant le signale.

    1. Le gérant ouvre Trésorerie › Historique des journées de caisse.
    2. Dans Écarts à justifier, il clique sur Ouvrir la journée, puis sur Justifier l'écart….
    3. Il voit l'attendu, le relevé et l'écart. Après avoir parlé avec le caissier, il tape le motif et clique sur Enregistrer le motif.

    Dans la même journée, l'onglet Vue détaillée (Z) montre le rapport Z : nombre de tickets, chiffre d'affaires, encaissements par moyen de paiement, fond, ventes en espèces, compté, versé et fond laissé. Les boutons Imprimer le Z et Rapport de clôture (A4) les impriment, à tout moment.

    Suivre la journée (gérant)

    • Vente › Tableau de bord : chiffre d'affaires du jour, tickets, panier moyen, marge, meilleures ventes.
    • Vente › Points d'attention : ce qui attend une action (ruptures, écarts, factures en retard…). Une tuile ouvre la bonne fenêtre.
    • Administration › Résumé du jour : le résumé de la journée, prêt à envoyer au gérant par WhatsApp. L'administrateur peut aussi le faire partir chaque soir par e-mail.

    Chapitre 5

    Le stock

    Pour qui : Gérant Magasinier

    Le stock baisse tout seul à chaque vente. Il monte quand vous saisissez une réception. Les inventaires, les pertes et les dates de péremption gardent le stock juste.

    Recevoir une livraison

    1. Ouvrez Achats › Saisir une nouvelle réception (sans commande). Pour une livraison commandée, passez plutôt par le bon de commande (chapitre 7).
    2. Choisissez le dépôt (surface de vente ou réserve), le fournisseur et tapez le numéro du bon de livraison.
    3. Scannez chaque produit ou tapez le début de son nom, puis Entrée.
    4. Sur chaque ligne, corrigez la quantité et le coût unitaire si besoin.
    5. Pour les produits périssables, tapez le numéro de lot et la date limite. La date est obligatoire.
    6. Cliquez sur Valider la réception. Un bon de réception (BR) est créé et le stock augmente.

    Pour passer de la marchandise de la réserve à la surface de vente, utilisez le menu Transfert › Transfert entre dépôts.

    Faire un inventaire

    L'inventaire se fait sans fermer le magasin : les ventes faites pendant le comptage sont déduites.

    1. Ouvrez Produit › Inventaires.
    2. Cliquez sur Nouvel inventaire global (tous les produits du dépôt) ou Nouvel inventaire partiel (des rayons choisis, ou des produits ajoutés un par un).
    3. Si vous le souhaitez, imprimez la Fiche de comptage pour compter en rayon.
    4. Dans la colonne Stock physique compté, tapez la quantité trouvée et Entrée pour passer à la ligne suivante. Chaque saisie est enregistrée : vous pouvez reprendre plus tard.
    5. Les lignes en rose ont un manquant, en bleu un surplus, en vert pas d'écart.
    6. Quand tout est compté, le gérant clique sur Clôturer l'inventaire…. Le stock est corrigé.
    Inventaire global

    Dans un inventaire global, les produits non comptés passent à zéro à la clôture (le logiciel demande confirmation). Dans un inventaire partiel, ils ne changent pas.

    Sortir la casse et les pertes

    1. Ouvrez Produit › Déstockages (pertes et casse).
    2. Choisissez le dépôt, puis scannez ou tapez le produit.
    3. Choisissez le type de sortie : Casse, Vol constaté, Péremption ou Consommation interne.
    4. Tapez la quantité et le motif. Le lot est choisi tout seul (le plus proche de sa date).
    5. Cliquez sur Enregistrer la sortie.

    Surveiller les dates de péremption

    Produit › Péremptions liste les lots qui périment bientôt, avec une alerte J-7, J-3, J-1 ou périmé. Choisissez l'horizon en haut (7 jours par exemple). Mettez ces produits en avant, faites une promotion, ou sortez-les en perte (type Péremption).

    Les stocks bas sont dans Produit › Stocks critiques et dans les Points d'attention. Le seuil d'alerte se règle sur la fiche de chaque article.

    Chapitre 6

    Clients à crédit et règlements

    Pour qui : Caissier Gérant

    Un client en compte (restaurant, école, boutique) peut acheter à crédit et payer plus tard. FEDONIX 360 suit ce qu'il doit et bloque au-delà de son plafond.

    Créer un client

    1. Ouvrez Client › Liste et cliquez sur Nouveau client. À la caisse, vous pouvez aussi le créer depuis la fenêtre F8.
    2. Tapez le nom, le téléphone, le NIU si besoin.
    3. Réglez le plafond de crédit (le maximum qu'il peut devoir) et le délai de paiement en jours.
    4. Choisissez son tarif : Détail, Gros ou Super gros. La caisse applique ses prix dès qu'il est choisi.
    5. Enregistrez.

    Vendre à crédit

    1. Ouvrez l'onglet V. crédit (en rouge).
    2. Appuyez sur F8, tapez le nom du client et choisissez-le. Son solde s'affiche en couleur : rouge s'il doit, vert s'il a un avoir.
    3. Ajoutez les produits comme pour une vente normale.
    4. Si le client donne un acompte en espèces, cliquez sur les billets reçus.
    5. Appuyez sur F4. L'acompte va dans la caisse, le reste va au compte du client avec sa date d'échéance.
    Plafond dépassé

    Si la vente fait dépasser le plafond du client, le code d'un gérant est demandé. Cette autorisation est enregistrée.

    Pour lui donner une facture A4 (avec l'échéance), appuyez sur F9 juste après la vente.

    Encaisser un règlement

    À la caisse :

    1. Dans la fiche de vente, ouvrez la liste Action et choisissez Règlement client (crédit).
    2. Choisissez le client : ce qu'il doit s'affiche.
    3. Choisissez le moyen : Espèces, MTN MoMo, Orange Money, Virement, Chèque ou Carte.
    4. Tapez le montant (vide = tout le solde) et, hors espèces, la référence.
    5. Cliquez sur Valider le règlement. Un reçu s'imprime. Les espèces reçues entrent dans le tiroir et sur le Z.

    Au bureau : ouvrez Client › Liste, cliquez sur le client puis sur Encaisser un règlement. Un règlement solde d'abord les ventes les plus anciennes.

    Suivre les clients

    • Client › Consulter un extrait de compte : toutes les ventes et règlements d'un client, et le relevé à imprimer pour lui.
    • Client › Situation des clients : ce que chacun doit, classé par retard (non échu, 1-30, 31-60, 61-90, plus de 90 jours).
    • Les clients en retard de paiement apparaissent aussi dans les Points d'attention.
    Chapitre 7

    Fournisseurs et commandes

    Pour qui : Gérant Responsable d'achat

    Ce chapitre est un résumé. Les commandes sont facultatives : vous pouvez toujours recevoir sans commande (chapitre 5).

    Les fournisseurs

    Dans Fournisseur › Liste des fournisseurs, créez la fiche de chaque fournisseur : téléphone, NIU, délai de paiement, délai de livraison. Ce que vous lui devez se suit dans Fournisseur › Situation des fournisseurs.

    Passer une commande

    1. Ouvrez Achats › Saisir un nouvel achat (bon de commande).
    2. Choisissez le fournisseur, le dépôt de livraison et la date souhaitée.
    3. Ajoutez les articles et tapez les quantités. Le prix d'achat est proposé.
    4. Cliquez sur Enregistrer et envoyer (ou Enregistrer le brouillon pour finir plus tard). Le bon de commande s'imprime en A4.
    • À la livraison : dans Achats › Bons de commande, ouvrez le bon et réceptionnez. Une livraison incomplète laisse un reliquat en attente.
    • La facture du fournisseur : Achats › Saisir une facture à partir des BL, ou Saisir une facture directe sans bon de commande. L'Échéancier fournisseurs montre ce qu'il faut payer et quand.
    • Que commander ? Achats › Proposition de commande calcule les quantités d'après les ventes des 4 dernières semaines et le stock d'alerte, et crée un bon par fournisseur en un clic.
    Chapitre 8

    Comptabilité et états

    Pour qui : Propriétaire Comptable

    FEDONIX 360 tient une comptabilité au plan SYSCOHADA révisé. Les écritures se passent toutes seules : vous n'avez rien à ressaisir. Ce chapitre est un résumé ; montrez ces écrans à votre comptable.

    Les écritures automatiques

    Chaque clôture de caisse (Z), règlement de client, facture et paiement de fournisseur, dépense et écart de caisse crée son écriture. Vous les voyez dans Comptabilité › Journaux. Le comptable peut aussi saisir des écritures à la main (loyer, banque…) avec Saisir une écriture.

    • Comptabilité › Grand livre et Balance générale : le détail et le solde de chaque compte.
    • Export CSV (cabinet comptable) : les écritures à transmettre à votre cabinet.
    • Les dépenses (loyer, ENEO, salaires, transport…) se saisissent dans Charge › Dépenses. Une dépense payée avec l'argent du tiroir se fait à la caisse : Action › Dépense payée en caisse, avec un bon de sortie à signer.

    La TVA

    Par défaut, le magasin n'est pas assujetti à la TVA (régime simplifié) : la TVA n'apparaît nulle part. Si vous êtes au réel, l'administrateur l'active dans Administration › Paramètres. Chaque mois, Fiscal › Déclaration de TVA donne le chiffre d'affaires par taux, la TVA collectée et déductible, et un document A4 pour remplir la déclaration DGI.

    Bilan et compte de résultat

    Comptabilité › Bilan et compte de résultat présente le bilan, le compte de résultat et le tableau des flux de trésorerie du SYSCOHADA, à imprimer en A4 ou à exporter pour la DSF. Les rapports de ventes (par jour, rayon, article, caissier…) sont dans Vente › Situation des ventes, avec export Excel.

    Avec votre comptable

    Les états financiers ne sont justes que si les factures des fournisseurs et les dépenses sont bien saisies. Faites-les vérifier par votre comptable avant de les déposer.

    Chapitre 9

    Les sauvegardes

    Pour qui : Propriétaire Gérant

    Toutes vos ventes, votre stock et votre comptabilité sont sur le PC. Si le PC est volé ou tombe en panne, seule une sauvegarde vous les rend. Prenez cinq minutes pour la régler.

    Ce que fait le logiciel tout seul

    • Une copie de la base chaque jour, sans arrêter la caisse. Chaque copie est vérifiée.
    • Les 14 copies les plus récentes sont gardées (nombre réglable).
    • Après 2 jours sans sauvegarde réussie, la barre d'état affiche Sauvegarde en retard en rouge.

    Régler une copie hors du PC

    1. Ouvrez Administration › Sauvegardes.
    2. En face de Copie de chaque sauvegarde vers, cliquez sur Choisir et choisissez une clé USB ou un dossier OneDrive ou Google Drive.
    3. Cliquez sur Sauvegarder maintenant et vérifiez que la sauvegarde apparaît dans la liste.

    Le bouton Copier sur une clé USB… fait une copie à la demande. Ces copies manuelles ne sont jamais effacées par la rotation. Une clé débranchée est signalée sans bloquer la sauvegarde.

    Le bon réflexe

    Une fois par semaine au moins, copiez la sauvegarde sur une clé USB et rangez la clé hors du magasin.

    Restaurer une sauvegarde

    La restauration remplace toutes les données du PC par celles de la sauvegarde. Elle est réservée à l'administrateur. En cas de doute, appelez FEDONG avant.

    1. Dans Administration › Sauvegardes, choisissez une sauvegarde dans la liste, ou cliquez sur Restaurer depuis un fichier….
    2. Le logiciel contrôle le fichier, puis demande de taper RESTAURER pour confirmer.
    3. Une copie « Avant restauration » de la base actuelle est faite d'abord, puis le logiciel redémarre.
    Chapitre 10

    La licence

    Pour qui : Propriétaire

    FEDONIX 360 s'utilise avec une licence liée au PC. Elle est mensuelle, annuelle ou à vie, selon la formule achetée, et fixe le nombre de PC et de magasins.

    Activer la licence

    1. Connectez-vous en administrateur et ouvrez Administration › Licence.
    2. Le code machine de ce PC s'affiche (4 groupes de lettres et chiffres). Cliquez sur Copier ou sur Envoyer par WhatsApp et envoyez-le à FEDONG.
    3. FEDONG vous renvoie une clé de licence. Elle commence par SG1.
    4. Collez la clé entière dans la zone Clé de licence.
    5. Cliquez sur Activer la licence. La date de fin s'affiche.

    Le lien Lire le contrat de licence affiche le contrat accepté à l'installation.

    Fin de licence et renouvellement

    Barre d'étatCe que cela veut dire
    Version d'essai (N j)Essai de 15 jours en cours. Activez une licence.
    Licence à renouveler (N j)La licence finit bientôt. Contactez FEDONG pour la renouveler.
    Licence expirée : ventes arrêtées dans N jLa licence est finie. Vous avez 15 jours de grâce pour la renouveler.
    Licence : ventes bloquéesLa caisse ne vend plus. Consultation, clôture de caisse et sauvegardes restent possibles.

    Pour renouveler, contactez votre vendeur FEDONG (voir la couverture de ce manuel). Il vous envoie une nouvelle clé : collez-la de la même façon dans Administration › Licence.

    Date et heure du PC

    Une date de Windows reculée bloque aussi la vente. Gardez la date et l'heure du PC à jour.

    • Plusieurs PC reliés au serveur central : activez la licence sur un seul PC. Les autres la reçoivent tout seuls, dans la limite du nombre de PC prévu.
    • PC changé ou en panne : demandez à FEDONG de transférer la licence sur le nouveau PC (il faudra son code machine).
    Chapitre 11

    Plusieurs PC et serveur central

    Pour qui : Propriétaire

    Avec deux caisses ou plus, ou plusieurs magasins, les PC sont reliés par un serveur central. C'est FEDONG qui installe le serveur et relie les PC. Ce chapitre explique comment cela fonctionne.

    Comment ça marche

    • Chaque PC garde sa propre base et continue de vendre sans réseau.
    • Dès que la connexion revient, les opérations partent au serveur toutes les 20 secondes. Les autres PC du magasin reçoivent le catalogue, les utilisateurs, les ventes et le stock.
    • Un autre magasin reçoit le catalogue commun, mais pas les ventes ni le stock des autres magasins.
    • La barre d'état montre Serveur : connecté, hors ligne ou non relié. Fichier › Synchroniser maintenant force l'envoi.

    Ajouter un PC au magasin

    1. Sur le PC principal, dans Administration › Caisses, créez une caisse et notez son code d'activation (6 chiffres).
    2. Installez FEDONIX 360 sur le nouveau PC. À la première ouverture, cliquez sur Rejoindre un magasin existant.
    3. Tapez l'adresse du serveur central (donnée par FEDONG) et le code d'activation, puis cliquez sur Rejoindre.
    4. Le PC récupère le catalogue, les utilisateurs et le stock du magasin.

    Le premier PC d'un magasin est relié au serveur dans Administration › Serveur central, avec la clé d'enrôlement que seul FEDONG connaît.

    Chapitre 12

    Questions fréquentes et dépannage

    Trouver de l'aide dans le logiciel

    • Le bouton rond ? en haut à droite, ou le lien Comment utiliser cette page ?, explique la page affichée. La touche F1 fait de même partout, sauf à la caisse où elle cherche un produit.
    • Ctrl+K ouvre un écran en tapant son nom, par exemple « clôture » ou « inventaire ».
    • Aide › Guide de démarrage, Aide › Quoi de neuf (les nouveautés après une mise à jour) et Aide › Raccourcis clavier.

    Questions fréquentes

    La fiche de vente dit « La caisse est fermée ».

    Ouvrez la caisse : bouton Ouvrir la caisse dans Trésorerie, puis Ouvrir la caisse… (chapitre 4). Si un caissier n'a pas de caisse attribuée, l'administrateur doit lui en donner une (chapitre 2).

    « Vous n'avez pas les droits pour cette action ».

    Votre rôle ne permet pas cette action. Demandez au gérant de la faire, ou à l'administrateur de vous donner le droit (Administration › Privilèges par utilisateur).

    J'ai oublié mon code, ou mon compte est bloqué.

    L'administrateur ouvre Administration › Utilisateurs, clique sur votre nom et tape un nouveau code, ou clique sur Débloquer. Si c'est le code de l'administrateur qui est perdu, appelez FEDONG.

    Le ticket ne s'imprime pas.

    Vérifiez que l'imprimante est allumée, a du papier et est branchée. Dans Administration › Paramètres, partie Imprimante ticket et tiroir-caisse (ce PC), cliquez sur Imprimer une page de test. Le ticket se réimprime ensuite avec F2. Si les accents sortent mal, changez la table de caractères proposée dans ces réglages.

    Un produit scanné n'est pas trouvé.

    Son code-barres n'est sur aucune fiche. Cherchez le produit par son nom, puis ajoutez le code-barres sur sa fiche (chapitre 3).

    Un produit est marqué « Épuisé » alors qu'il est en rayon.

    La réception n'a pas été saisie, ou la marchandise est encore dans la réserve. Saisissez la réception ou le transfert (chapitre 5). Le gérant peut aussi régler Ignorer la gestion des stocks dans Administration › Paramètres : la caisse vend alors même si le stock en machine est à zéro.

    Il y a un écart à la clôture.

    Recomptez avant de valider (bouton Recompter). Un écart au-delà du seuil reste « à justifier » : le gérant en parle avec le caissier puis tape le motif (chapitre 4).

    La barre d'état affiche « Sauvegarde en retard ».

    Ouvrez Administration › Sauvegardes et cliquez sur Sauvegarder maintenant. Si cela échoue, vérifiez la clé USB ou le dossier choisi (chapitre 9).

    La caisse ne vend plus à cause de la licence.

    Regardez le message de la barre d'état et le chapitre 10. Vérifiez la date du PC, puis contactez FEDONG avec le code machine affiché dans Administration › Licence.

    Internet est coupé : puis-je continuer à vendre ?

    Oui. Chaque PC vend sans réseau. Les opérations partent au serveur central dès que la connexion revient.

    Où sont mes données ?

    Dans le dossier %APPDATA%\Superette Gestion du PC (ancien nom du logiciel, gardé pour vos données), fichier superette.db. Ne le déplacez pas et ne le supprimez pas : utilisez les sauvegardes (chapitre 9).

    Comment se passent les mises à jour ?

    Les nouvelles versions sont fournies par FEDONG. Vos données, vos réglages et votre licence sont gardés. Après une mise à jour, la fenêtre Quoi de neuf présente les nouveautés.

    Besoin d'aide ?

    Contactez votre vendeur FEDONG : ses coordonnées sont sur la couverture de ce manuel. Ayez sous la main le nom du magasin, la version (en bas à gauche de l'écran, FEDONIX 360 v0.39.0) et, pour la licence, le code machine.
